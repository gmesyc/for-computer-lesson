把考試紀錄、常錯題、重點星號帶到別台電腦或手機

練習紀錄轉移工具

紀錄原本存在「這個瀏覽器」裡，換裝置就看不到。用這頁把紀錄匯出成一個檔案，在新裝置上開同一頁匯入即可。

1這台裝置目前的紀錄

以下是在這個瀏覽器中找到的練習資料。

這個瀏覽器還沒有任何練習紀錄，所以無法匯出。請先在題庫頁面作答一次，或直接在下方「匯入」把其他裝置的備份帶進來。
代碼適合用 LINE、Email 傳給自己，在新裝置貼到下面的匯入框即可。若代碼太長被截斷，請改用匯出檔案的方式。

2匯入到這台裝置

選擇匯入方式，貼上代碼或選擇備份檔。

合併規則：考試紀錄依時間合併並去除重複（最多留 50 筆）；常錯題取「答錯次數較多、連續答對次數較少」的那一邊，較保守；重點星號取聯集；範圍輪抽進度取已抽題數較多的一邊。

3怎麼用

  1. 把這個 transfer.html 和題庫網頁放在同一個 GitHub Pages repo（同一個網域底下）。
  2. 在舊裝置打開 你的網址/transfer.html，按「匯出備份檔」存成一個 .json 檔。
  3. 把這個檔案傳到新裝置（LINE、Email、Google Drive、隨身碟都可以）。
  4. 在新裝置打開同一個 transfer.html，選檔案後按「匯入」。
  5. 回到題庫頁重新整理，考試紀錄、常錯題、重點星號就都在了。
為什麼一定要放在同一個網域：瀏覽器的 localStorage 是以網域為單位隔離的。只有同一個 GitHub Pages 網址底下的頁面，才讀得到題庫頁存的資料；放在本機硬碟開（file://）會讀不到。
iPhone/iPad 注意：Safari 若長期沒開這個網站，可能會自動清掉資料，重要紀錄建議定期匯出一份。
資料只在你的瀏覽器與你自己選擇的檔案之間流動，沒有任何伺服器參與。
支援的網站：DP-900 模擬測驗、NCP-MCI 6.10 模擬測驗（自動偵測同網域下的其他題庫）。
